# IoT Hunter — Relicensing Readiness Checklist

Do not replace the current GPL-3.0 LICENSE until every applicable item is resolved.

- [ ] Confirm who owns the copyright in the original project.
- [ ] Review the Git history and identify every contributor.
- [ ] Determine whether contributor permissions allow relicensing under BUSL-1.1.
- [ ] Obtain written permission or other legally sufficient rights where needed.
- [ ] Identify code copied or adapted from GPL-licensed releases and assess whether it can be relicensed.
- [ ] Inventory third-party libraries, source files, snippets, generated code, icons, fonts, documentation, and other assets.
- [ ] Review each third-party license for compatibility and required notices.
- [ ] Confirm the exact licensed-work scope and release boundary.
- [ ] Finalize the 25-employee eligibility definition with legal counsel.
- [ ] Confirm the Additional Use Grant complies with BUSL-1.1.
- [ ] Confirm the Change License and Change Date for each version.
- [ ] Prepare a complete BUSL-1.1 LICENSE file using the official text without modifying its standard terms.
- [ ] Update documentation and metadata only after approval.
- [ ] Have a qualified software licensing lawyer review the final change.

## Current state

The repository's existing LICENSE remains GNU GPL v3. This checklist and the proposal documents do not change it.
